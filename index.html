Как это работает

01

Файл не покидает браузер

Изображение читается локально через File API — на сервер ничего не отправляется, сайт статический.

02

Ресемплинг Lanczos

Каждый новый пиксель считается взвешенной суммой соседних по функции Ланцоша — четче, чем обычное растягивание.

03

Шумоподавление и резкость

По желанию — лёгкое сглаживание шума перед увеличением и unsharp mask после, чтобы вернуть контур деталям.

04

Экспорт в нужном формате

Результат собирается на canvas и сохраняется в PNG, JPEG или WebP — сразу на ваше устройство.

Scale2Me — увеличение фотографий в браузере, без сервера. Работает как статическая страница на GitHub Pages.
